# 파머스테일 매거진 기획 (2026-10) — 제품·브랜드로 이어지는 글

> 사장님 2026-10-11: "매거진에서 우리 제품과 브랜드 스토리와 연관된, 이득이 될 만한 쪽으로 글을 쓰고 고치고 싶다."
> 이 문서가 매거진의 정본 기획서다. 옛 `docs/MARKETING_LAUNCH_CONTENT.md` 의 블로그 5편 계획('5종 화식'·'만성질환 보조' 등)은 옛 내용이라 이 문서가 대신한다.

## 0. 한 줄 요약

보호자가 **검색창에 실제로 치는 질문**에 답하는 글을 쓰고, 그 답이 **그 재료가 든 레시피·체험팩·앱**으로 자연스럽게 이어지게 한다.
글은 4개 묶음으로 나누고, **구매로 바로 이어지는 6편(새 글 4 + 고쳐 쓰기 2)** 부터 시작한다.

## 2. 사람들이 실제로 찾는 말 (구글 자동완성, 2026-10-11)

- **화식 자체**: 강아지 화식 뜻·장점·단점·부작용·비율·계산·급여량·보관·비용·추천·순위·시기 / 사료 바꾸는 법 / 사료 바꾸고 설사
- **우리 재료마다 "먹어도 되나요"**: 오리고기(효능·알러지) · 돼지고기(부위·급여량) · 소고기(부위·급여량) · 염통 · 간 · 브로콜리 · 블루베리 · 애호박 · 사과 · 무 · 양배추 · 비트(**"비트 소변·오줌"**까지 찾는다)
- **고민**: 입짧은 강아지(사료) · 밥 안 먹을 때 · 사료 토핑(추천) · 노견 화식 · 눈물·피부 사료(효능 주장이 되기 쉬워 피한다)
- **지역**: "강아지 화식 정기배송 인천" — 송도 주방 이야기와 잇기 좋다.
- 네이버 검색은 Claude 브라우저에서 막혀 확인하지 못했다(6절 네이버 블로그 옮겨 싣기 참고).

> 레시피와 재료(정본 `lib/recipe-ingredients.ts`)
> 닭 = 닭가슴살·간·염통 + 브로콜리·블루베리 / 오리 = 오리 안심·간·염통 + 애호박·사과 /
> 흑돼지 = 뒷다리살·간·염통 + 무·양배추 / 한우 = 목심·간·염통 + 비트·블루베리 /
> 공통 = 당근·단호박·시금치·현미·고구마 + 올리브유·연어유·강황·뉴트리 코어·난각분말

## 3. 글 묶음 4개 — 각각 하는 일

| 묶음 | 하는 일 | 글 끝에 잇는 곳 |
|---|---|---|
| **A. 화식 처음** | 사기 직전의 질문(장단점·양·보관·비용)에 답한다 | 체험팩 · 레시피 4종 · 앱 하루 양 |
| **B. 재료 이야기** | "○○ 먹어도 되나요"로 처음 오는 손님을 받는다 | 그 재료가 든 레시피 |
| **C. 우리 아이 고민** | 입 짧은 아이·노견·체중·알레르기 의심 | 체험팩 · 앱(하루 양·기록) |
| **D. 브랜드 이야기** | 보리·수비드·송도 주방·원재료 공개 — 믿음 | 우리 음식 · 우리 이야기 |

카테고리 이름도 이 4개로 정리한다(지금: 건강·가이드·영양 가이드·품종별 케어·브랜드 스토리).

## 4. 글 목록 (우선순위)

### P1 — 먼저 6편 (구매로 바로 이어짐)

| # | 제목(안) | 노리는 검색어 | 잇는 곳 |
|---|---|---|---|
| 1 | **[고쳐 쓰기]** 화식 처음 시작할 때 — 바꾸는 법·하루 양·보관·해동 (주소 유지) | 강아지 화식 시작·사료 바꾸는 법·화식 보관 | 체험팩 · 레시피 · 앱 |
| 2 | **[새]** 강아지 화식, 장점과 단점을 솔직하게 | 화식 뜻·장점·단점·부작용·비용 | 왜 화식인가 · 체험팩 |
| 3 | **[새]** 화식 하루 양, 이렇게 정해요 — 몸무게와 곁들여서·반반·화식만 | 화식 급여량·계산·비율 | 상품 화면 '하루에 얼마나' · 앱 |
| 4 | **[새]** 사료에 화식 곁들이기 — 토핑으로 시작하는 법 | 사료 토핑(추천)·입짧은 강아지 | 500g · 체험팩 |
| 5 | **[새]** 500g 한 봉 vs 앱 정기배송 — 우리 집엔 뭐가 맞을까 | 화식 비용·정기배송 비용 | 가게 · 앱 15% 할인 |
| 6 | **[고쳐 쓰기]** 음식 알레르기가 의심될 때 — 한 가지 고기로 살펴보는 법 | 닭 알레르기·단일 단백질 사료 | 4종 모두 한 가지 고기 · 원재료 전부 공개 (수의사 상담 먼저) |

### P2 — 재료 이야기 시리즈 (주 1~2편)

7. 강아지 오리고기, 먹어도 될까요 → 오리 화식
8. 강아지 돼지고기, 어느 부위를 얼마나 → 흑돼지 화식(뒷다리살)
9. 강아지 소고기, 부위 고르는 법 → 한우 화식(목심)
10. 닭가슴살만 먹여도 될까요 → 닭 화식(가슴살 + 간·염통 + 채소)
11. 염통과 간, 먹어도 되나요 → 4종 공통("염통과 간까지")
12. **비트 먹고 소변이 붉어졌어요 — 괜찮아요** → 한우 화식 (받은 손님의 놀란 문의를 줄이는 글)
13. 토핑 3편: 브로콜리·블루베리 / 애호박·사과 / 무·양배추 → 각 레시피
14. 공통 재료 2편: 시금치·고구마·단호박·현미 / 연어유·강황·달걀껍질 칼슘 → 우리 음식

### P3 — 브랜드 이야기 (월 1~2편)

15. 열세 살 '보리'에게서 시작했어요 — **사실 확인 필요**(8절)
16. 왜 수비드로 익히나요 → 우리 음식 · 왜 화식인가
17. 송도 주방의 일주일 — 조리부터 얼린 채 도착까지(발송 요일은 정본대로 — 가게 화·목 출고, 앱 정기배송 화요일 발송)
18. 원재료를 전부 적는 이유 → 상품 화면 원재료

### P4 — 기존 글 고쳐 쓰기 (우리 아이 고민)

19. BCS → **우리 아이 체형, 갈비뼈·허리·배로 보기**(조회 1위 — 주소 유지) → 앱 체중 기록
20. 노령견 식단 → **노견이 잘 먹는 한 끼** → 체험팩
21. 4주 다이어트 → **살 빼야 하는 아이, 하루 양부터** → 앱
22. 환절기 알러지 → **환절기 가려움, 집에서 할 것과 병원 갈 때**(약 이름·효과 단정 빼기) — 또는 내리기

- 가볍게 손보기: 주면 안 되는 음식 12가지 · 수제 간식 5가지(재료 시리즈·토핑 글로 잇는 줄만)
- 내리기: 관절 보조제(내린 글 주소는 매거진 첫 화면으로 영구 이동 — 옛 '정기배송 vs 단품'과 같은 방식)

## 5. 모든 글에 지키는 것

- **질병 치료·예방 효과를 말하지 않는다**(사료 표시·광고). "○○에 좋아요" 대신 **왜 넣었는지·어떻게 만드는지**.
- 약 이름·용량, **다른 회사 이름**(로얄캐닌 등)을 쓰지 않는다. 증상이 있으면 "수의사와 먼저".
- **영양소 %·비율 %를 쓰지 않는다** → '곁들여서·반반·화식만', 말과 막대로.
- 영어 전문용어(BCS·elimination diet·hypoallergenic) → 쉬운 우리말. '처방'·'언제든'·도착 요일 약속 금지.
  웹에서 '맞춤' 금지(앱 이야기일 때만 '몸무게에 맞춘 양').
- **숫자·사실은 정본에서**: 가격·배송·체험팩 = `lib/store/*` / 재료 = `lib/recipe-ingredients.ts` /
  열량 = 닭 130·오리 125·흑돼지 125·한우 145kcal(100g) / 보관 = "먹이기 전날 냉장실에서 녹이고, 녹인 팩은 3일 안에".
- 지금 웹 결제는 막혀 있다(스마트스토어 안내, 규칙177) — 글의 버튼은 **가게 화면(/store)** 으로 보낸다(결제가 열리면 저절로 이어진다).
- 글 길이 2,500~4,000자, 소제목 4~6개, **맨 위 3줄 요약**, 끝에 '자주 묻는 것' 2~3개.
- 말투: 해요체, 짧은 문장, 부모님 세대도 읽기 쉽게.
- 제품 연결은 **글 하나에 1~2곳만**(본문 중간 레시피 카드 1 + 끝 버튼 1) — 광고처럼 보이지 않게.

### 5-1. 본문 모양 쓰는 법 (2026-10-11 사장님 "본문을 더 가시성 좋게" — 첫 글로 시안)

| 쓰는 법 | 화면 |
|---|---|
| `:::요약 세 줄 요약` … `:::` (안에 `- ` 목록) | 맨 위 검은 테 상자, 번호 동그라미 |
| `## 소제목` 3개 이상 | 소제목마다 01·02 번호 + 위 굵은 선, 요약 아래 '이 글의 순서' 목차가 저절로 |
| `1. **1~2일째** — …` | 단계 표시(검은 동그라미 번호 + 세로선) |
| `\| 칸 \| 칸 \|` + `\|---\|---\|` | 표(오른쪽 칸 숫자 굵게) |
| `:::팁 제목` … `:::` / `:::주의` … `:::` | 초록 팁 상자 / 붉은 '이럴 땐 수의사와 먼저' 상자 |
| `==강조==` | 형광펜(글 하나에 2~4곳만) |
| `:::질문 질문 문장` … `:::` | 펼쳐 보는 Q 칸(자주 묻는 것) |
| `::레시피 오리` (한 줄) | 가게 상품 카드(이름·부위·가격 = 가게 정본) |

글 끝에는 저절로 '화식 4종'(글에서 언급한 레시피가 앞) + 앱 정기배송 한 줄이 붙는다. 초안 미리보기 = `/design-check-store?s=magazine-draft&m=2026-10&f=<파일>`.

## 6. 사이트 쪽 손볼 것 (코드 — 승인 후)

1. **글 끝 '이 글과 이어지는 레시피' 카드** + 본문 중간에 레시피 카드를 넣는 표시(예: `::레시피 오리`). 지금은 글 끝에 다른 글만 있다.
2. 가게 메뉴·바닥에 **'매거진' 길**(사장님 할 일 #68-③).
3. 카테고리 4개로 정리(3절).
4. **표지 사진**: 외부 무료 사진 9장 교체 — 생활감 사진(힉스필드, 장당 2크레딧) 또는 가게 사진 재사용.
5. 글쓴이 표기: '파머스테일'(수의사 감수가 실제로 있으면 그때만 '○○ 수의사 감수').
6. 네이버: 매거진 글을 네이버 블로그(blog.naver.com/farmerstail)에 요약으로 옮겨 싣고 원문 링크 — 한국 검색은 네이버 비중이 크다(사장님 손).
