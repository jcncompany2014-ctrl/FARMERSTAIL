# 부모님 세대 과제 테스트 대본 (2026-09, 시니어 사용성 1~3단계 검증)

목적: 하단 탭·글자 기준·설문 v4가 **실제 부모님 세대 두 분**에게 통하는지 본다.
검증 기준은 하나다. **"정기배송 시작해 보세요"를 도움 없이 3분 안에.**

## 준비 (사장님, 10분)
- 참가자 2명: 60대 이상, 스마트폰은 쓰되 우리 앱은 처음. 가족·지인 OK.
- 기기: 참가자 **본인 폰**이 최선(글자 크기 설정이 그 사람의 현실). 없으면 사장님 폰.
  참가자 폰이면 스토어에서 앱 설치 → 테스트용 계정으로 로그인해 둔다.
- 계정: 테스트용 계정 + 강아지 1마리 등록(설문·구독 없음). 카드 등록 화면 **직전**까지가 과제 끝 —
  실제 결제는 하지 않는다.
- 사장님 역할: 옆에 앉아 **말없이** 본다. 막혀도 30초는 기다린다. 질문받으면 "평소처럼 해보세요".
- 기록: 아래 관찰표를 종이나 메모앱에. 가능하면 화면 녹화(안드로이드 화면 녹화 / iOS 제어센터).

## 진행 (참가자 1명당 약 20분)
"오늘은 앱을 평가하는 거예요. 어머님(아버님)이 틀리는 게 아니라 **앱이 틀리는 걸** 찾는 거예요.
생각나는 대로 소리 내서 말해 주세요."

### 과제 1 — 정기배송 시작 (핵심, 3분)
> "이 강아지한테 정기배송을 시작해 보세요. 카드 넣는 화면이 나오면 멈추세요."

기대 경로: 하단 탭 **정기배송** → 큰 시작 버튼 → 설문(11문항 + 관문) → 결과 → 정기배송 신청 → 플랜 → 배송지.
- 시작~카드 화면까지 시간: ____분 ____초  (기준 3:00)
- 첫 탭으로 어디를 눌렀나: 홈 / 우리 아이 / 정기배송 / 발바닥 / 내 정보 / 기타 ______
- 도움 없이 끝냈나: 예 / 아니오 (막힌 곳: __________)

### 과제 2 — 설문 (과제 1 안에서 관찰)
- 한 화면에서 5초 이상 멈춘 질문: __________ (이유: 글자 / 뜻 / 어디 누를지)
- "선택"·"건너뛰기"를 이해했나: 예 / 아니오
- 관문에서 고른 것: 4개 더 답하기 / 건너뛰고 결과 보기
- 안내 문구(빨간 띠)가 뜬 화면: __________
- 잘못 누른 뒤 **이전**으로 돌아갈 줄 알았나: 예 / 아니오

### 과제 3 — 오늘 기록 남기기 (2분)
> "오늘 강아지 체중을 4.5kg으로 기록해 보세요."

기대 경로: 하단 가운데 **발바닥** → 체중 → 입력 → 저장.
- 발바닥이 무엇인지 알았나: 예 / 아니오 (첫 시도에서 누른 곳: ______)
- 완료 시간: ____분 ____초

### 마무리 질문 (3분)
1. "글자 크기는 어땠어요?" — 딱 좋다 / 조금 작다 / 많이 작다 (어느 화면: ____)
2. "가장 헷갈린 화면 하나만 꼽으면?"
3. "혼자 집에서 하라면 할 수 있겠어요?" — 예 / 아니오 (이유)
4. 인상적인 말 그대로 받아쓰기: "________________________"

## 판정
- **통과**: 두 분 모두 과제 1을 도움 없이 3분 안에. 글자 평가 "딱 좋다".
- **부분**: 한 분만 통과, 또는 특정 화면 하나에서만 막힘 → 그 화면만 고친다.
- **실패**: 두 분 모두 3분 초과 또는 첫 탭에서 정기배송을 못 찾음 → 홈 화면에 시작 버튼 추가 검토.
