# 이웃 할인

**무엇**: 지인·쓰레드·인스타 DM 등에서 온 *특정* 고객에게 어드민이 첫 박스 할인율을
도장처럼 붙인다(사장님 2026-09-27, 이름 "이웃 할인" — 농장 브랜드 톤).
불특정 다수용 **이벤트 코드 링크**(`/start?p=code`, /admin/promotions)와 다른 점은
"사람을 지정"한다는 것.

**규칙**
- 할인율 선택지 10·15·20·30·50% (`NEIGHBOR_RATES`) — 자유 입력 금지(0.9 오타 사고 방지).
- **첫 결제 1회만** — 청구 성공 후 `redeemed_order_id` 로 소진(CAS). 둘째 박스부터 정상 규칙.
- 등급·이벤트 코드와 겹치면 **더 큰 쪽 하나만**, 같으면 이웃 할인은 아껴 둔다(1회짜리라).
  서포터즈 체험가가 있으면 그것이 우선(`lib/payments/auto-discount.ts`).
- 전액 환불·취소되면 자동으로 되돌아온다(`tg_orders_reclaim_neighbor_discount`, 프로모션과 같은 전이).
- 카드 등록·주문 화면의 "둘째 박스부터 금액"(recurringOnly)에는 섞이지 않는다.

**동선**: 고객이 일반 가입 → 어드민 **고객 → 이웃 할인** → 이메일/이름 검색 → 할인율 선택 →
출처 메모(지인 이름·쓰레드 글 등) → 붙이기. 화면·영수증·메일엔 "이웃 할인"으로 보인다.

**정본**: `lib/payments/neighbor.ts`(순수 규칙+테스트), `neighbor_discounts` 테이블
(service_role 전용), `orders.discount_reason = 'neighbor'`, 규칙132.
