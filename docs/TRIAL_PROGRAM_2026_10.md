> 목적: 사장님이 결정할 것 5개를 앞에 두고, 나머지는 **지금 시스템으로 바로 굴러가게** 설계했다.
> 새로 만드는 코드는 어드민 "체험단 현황" 화면 하나뿐이다(반나절).

## 1. 왜 하나 (목표를 숫자로)
| 목표 | 지표 | 목표치 |
|---|---|---|
| 후기·사진 자산 | 인스타 피드 후기 · 스마트스토어 리뷰 · 언박싱 사진 | 각 20건 이상 |
| 전환 증명 | 체험 → 2회차 정상가 결제 전환율 | **40% 이상**(12두) |
| 제품 검증 | 2주 체크인 완료율 · 기호성 "잘 먹음" 비율 · 변 이상 신고 | 완료 80% · 잘 먹음 70% · 변 이상 ≤10% |
| 채널 비교 | 프로모션 코드별 가입 수 vs 결제 수 | 인스타 vs 지인/QR 중 무엇이 싼 채널인지 |

전환율 40%는 첫 박스 큰 할인 + 카드 등록 구조에서의 보수적 목표다. 카드 없는 "완전 무료"는 전환이 한 자리 수로 떨어진다(BETA_OUTREACH 시절 교훈 + 업계 통례).

## 2. 체험단 여정 (고객이 보는 순서)
1. **신청** — 인스타 게시물/DM·지인 링크로 **신청 폼**(Tally/구글폼, 별도 개발 X): 보호자 이름·연락처·인스타 계정·강아지 이름/견종/체중/나이·알레르기·현재 밥·사진 1장·**동의 3개**(개인정보 수집, 후기·사진 2차 사용, 자동결제 고지 확인).
2. **선발** — 사장님이 30두 선발(체중 분산·알레르기 5두). 선발자에게 **프로모션 링크** 발송: `farmerstail.kr/start?p=trial2510`.
   - 링크 문구는 반드시 "링크 타고 1분 설문 → 가입 → 앱 설치" 순서(앱부터 깔면 할인이 안 붙는다 — 기존 규칙).
3. **설문·가입** — 웹 /start 라이트 설문 → 카카오 가입 → 앱 설치 → 앱에서 강아지 확인 → 정기배송 시작 → **카드 등록** → 첫 박스 결제(80% 할인 자동 적용, 계정당 1회).
4. **첫 박스** — 화요일 발송(마감 일요일). 박스 안에 **체험단 카드**(A6 인쇄물): 2주 미션 3개 + 후기 표기 문구 + 해지·건너뛰기 방법 + 상담 카톡.
5. **2주 미션** — ① 도착 2일 내 언박싱 사진(앱 기록 > 사진 + 인스타 스토리 @farmerstail) ② 앱 **2주차 체크인**(이미 있는 기능: 밥 잘 먹는지·변·체중) ③ 후기 1건(인스타 피드 또는 스마트스토어).
6. **2회차** — 별도 조치 없으면 정상 구독가(정가 −15%)로 자동 결제. 계속할지 말지는 **일요일 마감 전** 앱 정기배송 탭에서 건너뛰기/해지. 이 사실을 신청 시·박스 카드·앱 화면 세 곳에서 고지.
7. **결산** — 미션 완료자 보상(간식 동봉) · 우수 후기 3명 환불 · 통화 10명(선택) · 리포트.

## 4. 지금 시스템으로 되는 것 / 안 되는 것
**되는 것 (코드 수정 없음)**
- 첫 박스 할인: `/admin/promotions` 에서 코드·할인율·기간·인원 상한 설정 → 링크 하나. 계정당 1회, 첫 결제에 자동 적용, 소진 표시. 코드별 **가입 수 vs 결제 수**가 어드민에 이미 뜬다 → 채널 비교.
- 피드백: 앱 2주차·4주차 체크인(밥·변·체중), 첫 체크인 → `feeding_outcomes`(별점·기호성·변·체중·사진·코멘트·해지 사유) 자동 적재. 이건 예전 30두 클로즈드 베타에 쓰던 장치 그대로다.
- 사진 요청: 사진 업로드 토큰(`photo_request_tokens`) — 보호자에게 링크로 사진 받기.
- 알림: 배송·체크인 푸시 크론 + 어드민 푸시 캠페인(세그먼트).
- 해지·건너뛰기: 앱 정기배송 탭.

**안 되는 것 (기획으로 피함)**
- **첫 박스 0원**: 결제 크론이 0원 청구를 일부러 건너뛴다(카드 최소 금액 미달 → 실패 카운트 → 구독 정지 사고 방지, 2026-07-29 결정). 그래서 "무료"가 아니라 "80% 할인". 무료를 꼭 해야 하면 별도 결제 경로가 필요하다(2~3일 개발 + 결제 감사).
- 2회차 이후 추가 할인(예: 3회차까지 20%): 프로모션은 첫 결제 1회만. 미션 보상은 **수동**(사은품 동봉·어드민 환불)으로.
- 균일가(9,900원): 할인율 방식이라 강아지마다 금액이 다르다. 균일가는 개발 필요.

**개발 1건 (반나절)**: `/admin/beta-cohort` 를 "프로모션 코드별 체험단 현황"으로 일반화 — 코드 `trial2510` 로 가입한 계정의 강아지·카드 등록·첫 박스 결제·2주 체크인·후기(feeding_outcomes)·2회차 결제/해지를 한 표로, 인쇄 → PDF. 지금 화면은 `closed_beta_2026_q3` 고정.

## 5. 돈 (사장님 원가율 확정 필요)
가정: 평균 박스 구독가 55,000원(소형 곁들임 37,000 ~ 중형 반반 90,000 혼합), 원가율 45%.
| 항목 | 계산 | 금액 |
|---|---|---|
| 첫 박스 할인 부담(매출 포기) | 30두 × 55,000 × 80% | 1,320,000원 |
| 첫 박스 실제 현금 지출(원가 − 받은 돈) | 30 × (55,000×45% − 11,000) | 약 412,000원 |
| 보상(간식 동봉 30 + 우수 후기 환불 3) | 30×5,000 + 3×55,000 | 315,000원 |
| 인쇄·통화·잡비 | | 100,000원 |
| **총 투입** | | **약 83만 원 현금 / 매출 포기 포함 약 180만 원** |
| 기대 매출 | 전환 12두 × 55,000 × 평균 6회 잔존 | **약 396만 원** |

손익분기 전환율 ≈ 25%(6회 잔존 가정). 원가율이 55%면 현금 지출이 약 58만 원으로 오른다.

## 6. 법·고지 체크리스트 (빠지면 사고 나는 것)
- **후기 대가 표시**(공정위 추천·보증 심사지침): 후기 첫 부분에 "파머스테일로부터 제품을 할인 제공받아 작성" 문구, 인스타는 `#광고` 또는 '유료 광고 포함' 태그. 박스 카드에 문구를 **그대로 복사할 수 있게** 인쇄.
- **자동결제 고지**(전자상거래법): 첫 박스 후 정상가 자동 결제 사실·금액·해지 방법을 신청 폼·박스 카드·앱 결제 화면 세 곳에서. 마감(일요일) 전 해지하면 청구 없음을 명시.
- **개인정보**: 신청 폼 수집 항목 최소화, 보관 기간(체험단 종료 후 3개월), 후기·사진 2차 사용 범위(인스타·홈페이지·스마트스토어)와 기간 동의를 **별도 체크**.
- **경품**: 현금성 보상이 1인 5만 원을 넘으면 기타소득 원천징수 이슈 — 우수 후기 환불(55,000)은 "환불"이라 무관하지만, 현금·상품권으로 바꾸면 5만 원 이하로.
- **표시광고**: "처방"·"치료" 표현 금지(기존 규칙), 체험단 모집 문구도 "맞춤 식단" 톤 유지.
