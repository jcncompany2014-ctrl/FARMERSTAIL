# 파머스테일 구독 체험단 기획

> [!summary] 한눈에 보기
> - **무엇**: 강아지 30두에게 첫 박스를 **80% 할인**으로 보내고, 2주 뒤 **솔직한 후기 1건**을 받는다.
> - **왜**: 후기·사진 자산 20건 이상 확보, 체험→정기구독 **전환율 40%** 증명, 제품(기호성·변·체중) 검증, 채널별 성과 비교.
> - **어떻게**: 지금 있는 장치(프로모션 링크·앱 체크인·피드백 테이블·어드민 집계)로 굴린다. 새 개발은 **어드민 화면 1개**뿐.
> - **언제**: 10/6(월) 모집 → 10/14(화) 첫 발송 → 11/4 결산. 총 5주.
> - **돈**: 현금 지출 약 83만 원(원가율 45% 가정). 전환 40%면 기대 매출 약 396만 원.
> - **못 하는 것**: 첫 박스 **0원(무료)**. 결제 시스템이 0원 청구를 막아 둔 상태라 "큰 할인"으로 간다.

## 1. 사장님이 정할 것 5개

> [!question] 이 5개만 답해 주시면 바로 시작합니다. 추천안에 ✅ 표시.

| # | 결정 | 추천안 | 다른 선택지 | 결정 |
|---|---|---|---|---|
| 1 | **인원** | ✅ 30두 (소형 18 · 중형 9 · 대형 3, 알레르기 있는 아이 5두 포함) | 20두 = 운영 편함 / 50두 = 후기 많음·원가↑ | ☐ |
| 2 | **첫 박스 혜택** | ✅ 80% 할인 + 배송비 무료 (4kg 곁들임 37,200원 → 약 7,400원) | 70% / 90% · **100%는 불가**(→ §5) | ☐ |
| 3 | **후기 채널** | ✅ 인스타 피드 1건 + 스마트스토어 리뷰 1건 | 인스타만 | ☐ |
| 4 | **미션 보상** | ✅ 2회차 박스에 간식·토퍼 동봉(수동) + 우수 후기 3명은 2회차 박스 환불 | 보상 없음 / 스탬프 보상(내용 미정이라 지금은 X) | ☐ |
| 5 | **일정** | ✅ 10/6 모집 · 10/14 첫 발송 · 11/4 결산 | 한 주 뒤로 | ☐ |

> [!tip] 왜 30두인가
> 예전 클로즈드 베타가 30두였고, 어드민 집계 화면·피드백 테이블이 그 규모에 맞춰져 있다. 한 사람이 DM·도착 확인·후기 독려를 손으로 할 수 있는 상한이기도 하다.

## 2. 목표와 지표

| 목표 | 무엇을 세나 | 목표치 | 어디서 보나 |
|---|---|---|---|
| 후기·사진 자산 | 인스타 피드 후기 · 스마트스토어 리뷰 · 언박싱 사진 | 각 **20건 이상** | 인스타 태그 · 스마트스토어 · 앱 사진 기록 |
| 전환 증명 | 체험 → 2회차 정상가 결제 | **40% 이상 (12두)** | 어드민 프로모션(코드별 가입 vs 결제) · 체험단 현황 화면 |
| 제품 검증 | 2주 체크인 완료율 · "잘 먹음" 비율 · 변 이상 신고 | 80% · 70% · 10% 이하 | 어드민 체험단 현황(피드백 테이블) |
| 채널 비교 | 코드별 가입 수 대비 결제 수 | 인스타 vs 지인·QR 중 싼 채널 확인 | 어드민 프로모션 |

> [!note] 전환율 40%가 보수적인 이유
> 카드를 등록하고 첫 박스를 결제한 사람만 체험단이 된다. 카드 없는 "완전 무료" 체험은 전환이 한 자리 수로 떨어지는 게 통례라 처음부터 카드 등록 구조로 잡았다.

## 3. 체험단 여정 (고객이 보는 순서)

```
① 신청 폼 → ② 선발 DM(링크) → ③ 1분 설문 → 카카오 가입 → 앱 설치 → 카드 등록 → 첫 박스 결제(80% 할인)
→ ④ 화요일 발송(박스 안 체험단 카드) → ⑤ 2주 미션 3개 → ⑥ 2회차 정상가 자동 결제(일요일 전 해지 가능) → ⑦ 결산·보상
```

### ① 신청 (개발 없음 · Tally 또는 구글폼)
수집 항목은 아래가 전부. 더 받지 않는다(개인정보 최소 수집).

- [ ] 보호자 이름 · 연락처(카톡 가능한 번호) · 인스타 계정
- [ ] 강아지 이름 · 견종 · 체중 · 나이 · 중성화 여부
- [ ] 알레르기 있는 재료(있으면) · 지금 먹는 밥(사료/화식/섞음)
- [ ] 강아지 사진 1장
- [ ] **동의 3개(각각 체크)**: 개인정보 수집·이용(보관 3개월) / 후기·사진 2차 사용(인스타·홈페이지·스마트스토어, 1년) / "첫 박스 뒤 정상가 자동 결제, 일요일 전 해지 가능" 확인

### ② 선발
- 30두. 체중 분산(소형 18 · 중형 9 · 대형 3) + **알레르기 있는 아이 5두**(알레르기 대응 레시피 검증용).
- 인스타 활동이 있는 계정 우선(후기 노출), 단 절반은 일반 보호자(솔직한 피드백).
- 선발자에게 **선발 DM**(§8 문안) + 프로모션 링크 `farmerstail.kr/start?p=trial2510`.

> [!warning] 링크 문구 순서가 할인을 좌우한다
> "링크 타고 1분 설문 → 가입 → **그다음** 앱 설치". 앱부터 깔고 가입하면 링크의 코드를 앱이 모르니 **할인이 안 붙는다**. 이건 기존 프로모션 규칙 그대로다.

### ③ 설문·가입·첫 결제 (전부 기존 흐름)
웹 1분 설문 → 카카오 가입(코드가 계정에 박힘) → 앱 설치 → 정기배송 시작 → 카드 등록 → 첫 박스 결제에 80% 자동 적용(계정당 1회, 자동 소진).

### ④ 첫 박스 (10/14 화요일 발송, 마감 10/12 일요일)
박스 안에 **체험단 카드**(A6 인쇄물 1장, §8 문안): 미션 3개 · 후기 표기 문구 · 해지·건너뛰기 방법 · 상담 카톡.

### ⑤ 2주 미션 3개
| 미션 | 언제 | 어떻게 확인 |
|---|---|---|
| 언박싱 사진 1장 | 도착 2일 내 | 앱 하단 발바닥 → 사진 기록 + 인스타 스토리 @farmerstail 태그 |
| 2주차 체크인 | 도착 12~14일 | 앱이 알림을 보낸다(기존 크론). 밥 잘 먹는지·변·체중 4문항 |
| 후기 1건 | 2주 내 | 인스타 피드 또는 스마트스토어 리뷰. 사진 3장 + 좋은 점·아쉬운 점 |

### ⑥ 2회차
별도 조치가 없으면 **정상 구독가(정가 −15%)** 로 2주마다 자동 결제. 계속하지 않을 사람은 **일요일 마감 전** 앱 정기배송 탭에서 건너뛰기/해지. 이 사실을 **신청 폼 · 박스 카드 · 앱 결제 화면** 세 곳에서 알린다.

### ⑦ 결산·보상
미션 3개 완료자 → 2회차 박스에 간식 동봉(수동). 우수 후기 3명 → 2회차 박스 환불(어드민 환불 화면). 원하는 사람 10명 → 30분 통화.

## 5. 지금 시스템으로 되는 것 / 안 되는 것

### 되는 것 (코드 수정 없음)
| 장치 | 어디 | 체험단에서 쓰는 방법 |
|---|---|---|
| 프로모션 링크 | 어드민 → 프로모션 | 코드·할인율·기간·인원 상한 → 링크 하나. 계정당 1회, 첫 결제에 자동 적용·소진. **코드별 가입 수 vs 결제 수**가 이미 집계됨 |
| 2주차·4주차 체크인 | 앱(자동 알림) | 밥·변·체중 4문항 = 제품 검증 데이터 |
| 피드백 테이블 | 앱 첫 체크인 → 자동 저장 | 별점·기호성·변·체중·사진·코멘트·**해지 사유** |
| 사진 요청 링크 | 앱 | 보호자에게 사진 올리는 링크 보내기 |
| 푸시 캠페인 | 어드민 → 푸시 | 체험단만 골라 알림 보내기 |
| 해지·건너뛰기 | 앱 정기배송 탭 | 고객이 직접. 마감 일요일 |

### 안 되는 것 (기획으로 피함)
> [!danger] 첫 박스 0원(무료)은 불가
> 결제 시스템이 **0원 청구를 일부러 건너뛴다**. 7월 결제 감사 때 "카드 최소 금액 미달 → 결제 실패 3번 → 구독 정지 + 프로모션 소진"이라는 사고를 막으려 넣은 규칙이다. 그래서 무료 대신 **80% 할인**. 꼭 무료여야 하면 별도 결제 경로를 새로 만들어야 한다(2~3일 + 결제 감사).

- **2회차 이후 추가 할인**(예: 3회차까지 20%): 프로모션은 첫 결제 1회만. 그래서 보상은 **수동**(간식 동봉·환불).
- **균일가**(예: 9,900원): 할인율 방식이라 강아지마다 금액이 다르다. 균일가는 개발 필요.

### 개발 1건 · 어드민 "체험단 현황" (반나절)
지금 있는 베타 현황 화면(예전 30두 클로즈드 베타용, 코호트 고정)을 **프로모션 코드별**로 일반화한다. 코드 `trial2510`로 가입한 계정을 한 표로:
`강아지 · 가입일 · 카드 등록 · 첫 박스 결제 · 언박싱 사진 · 2주 체크인 · 별점/기호성/변 · 후기 제출(수동 체크) · 2회차 결제/해지 · 해지 사유` + 인쇄 → PDF.

## 6. 돈

> [!info] 가정: 평균 박스 구독가 55,000원(소형 곁들임 37,000 ~ 중형 반반 90,000 섞임), **원가율 45%**. 원가율 확정값 주시면 다시 계산.

| 항목 | 계산 | 금액 |
|---|---|---|
| 첫 박스 할인 부담(매출 포기) | 30 × 55,000 × 80% | 1,320,000원 |
| 첫 박스 실제 현금 지출(원가 − 받은 돈) | 30 × (55,000 × 45% − 11,000) | 약 412,000원 |
| 보상(간식 30 + 우수 후기 환불 3) | 30 × 5,000 + 3 × 55,000 | 315,000원 |
| 인쇄·통화·잡비 | | 100,000원 |
| **총 투입** | | **현금 약 83만 원** (매출 포기 포함 약 180만 원) |
| 기대 매출 | 전환 12두 × 55,000 × 평균 6회 잔존 | **약 396만 원** |

- 손익분기 전환율 ≈ **25%**(6회 잔존 가정).
- 원가율 55%면 현금 지출 약 58만 원, 35%면 약 25만 원.

## 7. 법·고지 체크리스트 (빠지면 사고)

- [ ] **후기 대가 표시**(공정위 추천·보증 심사지침): 후기 **첫 부분**에 "파머스테일로부터 제품을 할인 제공받아 작성한 후기입니다". 인스타는 `#광고` 또는 '유료 광고 포함' 태그. 박스 카드에 **복사해서 쓸 수 있게** 인쇄.
- [ ] **자동결제 고지**(전자상거래법): 첫 박스 뒤 정상가 자동 결제 사실·금액 기준·해지 방법을 **신청 폼 · 박스 카드 · 앱 결제 화면** 세 곳에서. 일요일 전 해지하면 청구 없음 명시.
- [ ] **개인정보**: 수집 항목 최소(§3-①), 보관 기간(종료 후 3개월), 후기·사진 2차 사용 범위·기간 **별도 체크박스**.
- [ ] **경품**: 현금·상품권 보상은 1인 **5만 원 이하**(기타소득 원천징수). 우수 후기 "환불"은 무관.
- [ ] **표시광고**: "처방"·"치료"·"수의사 추천" 표현 금지(기존 브랜드 규칙). 모집 문구도 "맞춤 식단" 톤.

## 9. 결산 리포트에 담을 것
- 퍼널 숫자: 신청 → 선발 → 가입 → 카드 → 첫 결제 → 체크인 → 후기 → 2회차 결제
- 별점·기호성 분포, 변 이상·체중 변화
- 해지 사유 카테고리(가격/기호성/변/생활)와 통화 5명의 말 그대로
- 코드별(채널별) 가입 vs 결제 → 다음 기수 모집 채널
- 우수 후기 3건 링크
- 다음 기수 개선 3가지
