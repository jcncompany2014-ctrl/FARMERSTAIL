## 1. [사장님] Play Console 계정 마무리

1. DUNS 번호 입력 — 사업자명·주소가 **DUNS 등록정보와 글자까지 일치**해야 함
2. 등록비 $25 결제 (일회성)
3. 신분증·사업자 확인 요청이 오면 즉시 응답 (검증 며칠 소요)
4. 조직 계정이므로 **"테스터 12명 × 14일" 의무 면제** — 심사만 통과하면 바로 프로덕션 출시 가능

## 2. [사장님] 맥 셋업 후 키스토어 생성 (한 번만)

```bash
cd farmerstail-app/android
keytool -genkey -v -keystore farmerstail-release.jks -keyalg RSA \
  -keysize 2048 -validity 10000 -alias farmerstail
```

- 이름·조직 물어보면 사업자 정보로 입력
- **비밀번호는 안전한 곳에 2군데 백업** (비밀번호 관리자 + 종이/금고)
- 그다음 `android/keystore.properties` 작성 (예시: `keystore.properties.example` 복사)

⚠️ **키스토어를 잃어버려도 Play App Signing 을 쓰면 재발급 신청으로 복구 가능**하지만,
백업이 있으면 그 절차(수일)를 안 겪는다. `.jks`·`keystore.properties` 는 절대 커밋 금지(gitignore 처리됨).

---

## 3. [사장님] Firebase 프로젝트 — 푸시 알림용

앱 푸시(FCM)를 쓰려면 필요하다. 안 하면 앱은 돌지만 **네이티브 푸시가 안 온다**.

1. [console.firebase.google.com](https://console.firebase.google.com) → 프로젝트 만들기
2. Android 앱 추가 → 패키지명 **`com.farmerstail.app`** (정확히)
3. `google-services.json` 다운로드 → `android/app/` 에 넣기 (커밋 금지 — gitignore 됨)
4. 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성 → 그 JSON 에서 Vercel 환경변수 3개 채우기:
   - `FCM_PROJECT_ID`
   - `FCM_CLIENT_EMAIL`
   - `FCM_PRIVATE_KEY` (PEM 전체, 줄바꿈 포함)

   (이 이름들은 `lib/push/native.ts` 가 읽는 값이다.)

## 4. [Claude] AAB 빌드 (맥에서 함께)

```bash
npx cap sync android          # 웹 설정·플러그인 반영
cd android && ./gradlew bundleRelease
# 결과: android/app/build/outputs/bundle/release/app-release.aab
```

빌드 전 확인할 것 (제가 합니다):
- `versionCode` 올리기 (업로드마다 +1 필수, 지금 1)
- 아이콘·스플래시 (logo-ink 자산으로 생성)
- allowNavigation 반영 확인

## 5. [사장님] 실기기 테스트 — 출시 전 필수

AAB 만들기 전에 폰에 직접 설치해서 확인:

- [ ] 앱 실행 → 홈 화면 정상 (PWA 벽 안 뜸)
- [ ] **카드 등록 흐름 완주** ← allowNavigation 수정의 검증 지점. 토스 결제창이
      열리고 카드사 인증까지 가는지
- [ ] **카카오 로그인** 완주 (카카오 → 우리 사이트로 복귀)
- [ ] 푸시 알림 수신 (Firebase 설정 후)
- [ ] 뒤로가기 동작 (앱이 종료되지 않고 화면 계층 이동)

## 6. [사장님] Play Console 스토어 등록정보

### 필수 입력
- **앱 이름**: 파머스테일
- **간단한 설명** (80자): 예) "우리 아이 몸에 맞춘 신선 화식, 2주마다 문 앞으로"
- **자세한 설명** (4000자): 설문 → 맞춤 레시피 → 정기배송 흐름 설명
- **앱 아이콘** 512×512 PNG
- **그래픽 이미지** 1024×500
- **스크린샷** 최소 2장 (폰 기준, 저는 시뮬레이터/실기기에서 뽑는 것 도와드림)
- **개인정보처리방침 URL**: `https://www.farmerstail.kr/legal/privacy` ✅ 이미 있음
- **카테고리**: 쇼핑 (또는 라이프스타일)

### 데이터 보안 설문 — 우리 실제 수집 항목
개인정보처리방침 기준. **"수집함 + 전송함"** 으로 답할 항목:

| 카테고리 | 항목 | 목적 | 필수 |
|---|---|---|---|
| 개인 정보 | 이름, 이메일, 전화번호, 주소 | 계정 관리·주문 배송 | 필수 |
| 개인 정보 | 출생연도 | 만 14세 확인(법정) | 필수 |
| 금융 정보 | 결제 정보 | 주문 결제 | 필수 |
| 앱 활동 | 앱 내 검색·상호작용 | 서비스 개선 | 선택 |
| 기기 ID | 푸시 토큰 | 알림 발송 | 선택 |
| 사진 | 사용자 업로드 사진 | 반려견 기록 | 선택 |
| 건강·피트니스 | 반려견 체중·건강 기록 | 맞춤 식단 계산 | 필수 |

⚠️ **결제 정보는 "수집하지 않음"이 맞을 수 있다** — 카드번호는 토스페이먼츠가
직접 받고 우리는 빌링키만 저장한다(카드번호 미보유). 설문에서 "결제 정보를
앱이 수집하나요"에 정확히 답하려면 **"카드 정보는 결제대행사가 처리"** 로
분류. 애매하면 개인정보처리방침 문구를 그대로 따른다.

- 전송 중 암호화: **예** (전부 HTTPS)
- 데이터 삭제 요청 경로 제공: **예** (앱 내 회원탈퇴 + 5년 후 자동 파기 크론)

### 콘텐츠 등급 설문
- 앱 유형: 쇼핑/유틸리티
- 폭력·성적 콘텐츠·도박 등 전부 **없음**
- → 전체 이용가 등급 나올 것

1. 프로덕션 트랙에 AAB 업로드

| 사유 | 우리 대비 |
|---|---|
| 개인정보처리방침 누락/불일치 | ✅ URL 있음, 데이터 보안 설문과 내용 일치시킬 것 |

| 데이터 보안 설문 부정확 | 위 표대로 정확히 |
| 대상 연령 부적합 | 만 14세 이상 서비스 — 설문에서 성인 대상 명시 |
