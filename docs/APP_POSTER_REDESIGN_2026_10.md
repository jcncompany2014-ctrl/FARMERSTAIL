### 글꼴·모양
- 제목·레시피 이름 = Black Han Sans, 큰 숫자 = Anton, 나머지 = Pretendard. (Black Han Sans 는 쉼표가 마침표처럼 보여 숫자엔 쓰지 않는다.)
- 모서리 4px. **도장 그림자(2px 먹선 + 4px 4px 0 먹)는 화면당 한 곳** — 그 화면의 핵심 카드.
- 윗줄: 홈 = 작은 로고 + 알림 종 / 탭 화면 = 화면 이름 / 깊은 화면 = ← + 이름. 아래 탭 5칸, 가운데 기록 버튼은 바 안쪽.
- 글자 크기는 시니어 사용성 스케일(12/14/16/18 + 제목)을 지킨다.

## 단계

1. **바탕 공사** — 앱 범위(`[data-ft-chrome="app"]`)의 색 토큰·글꼴·공통 부품(윗줄·아래 탭·버튼·카드·칩·세그먼트·스위치·시트·토스트·빈 상태·뼈대). 웹 화면은 그대로(웹 9장 화면 사진 비교로 확인). 로딩 화면·네이티브 바탕 흰색(셸 3세대)도 이 단계에서 가지에 넣었다(아래).
2. **화면 묶음** — ① 홈·기록·공통 → ② 우리 아이·분석 → ③ 정기배송·결제 → ④ 내 정보 → ⑤ 로그인 → ⑥ 설문(새 틀). 묶음마다 시안과 나란히 화면 사진 비교.
3. **새 기능** — 새 첫 화면(Y1~Y7, 사진 단계 Y5b·Y5c), 결과 화면 둘러보기(TR0~TR4).
4. **켜는 날** — 가지를 main 으로 합치고, 같은 커밋으로 새 AAB·iOS 빌드(셸 3세대)를 만들어 스토어에 낸다.

### 네이티브 셸 세대 — 흰 바탕을 켜도 옛 앱이 깨지지 않게 (규칙58·84·149·166)
웹 배포는 모든 설치 버전에 바로 닿지만 네이티브 색(폰 화면·상태바·홈바)은 스토어 업데이트로만 바뀐다. 앱이 UA 끝에 붙이는 `FtShell/N` 으로 웹이 셸 색을 안다.
