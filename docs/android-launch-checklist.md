# Android 출시 체크리스트 (Google Play)

> 2026-08-09 작성. `android/` 셸은 생성 완료(ec1f11a), 코드는 RC 상태.
> 표기: 🙋 사장님이 직접 / 🤖 값을 주면 코드 쪽 처리 / ⏳ 대기·심사
>
> 상세 배경은 `docs/native-deploy.md`, iOS 는 `docs/ios-launch-checklist.md`.

---

## ⚠️ 먼저 알아야 할 함정 3개

### 1. 계정 유형이 출시 속도를 좌우한다 — **사업자(조직)로 가입할 것**
Play Console 은 **개인(Personal) 계정**으로 새로 가입하면, 프로덕션 출시 전에
**클로즈드 테스트를 일정 인원·일정 기간 이상 돌려야** 한다(대략 테스터 12명
이상 × 14일 연속 — 정확한 수치는 가입 시 Play Console 화면에 표시되니 그때
확인). 이걸 모르고 개인으로 가입하면 **출시가 2주 이상 밀린다.**

**조직(Organization) 계정은 이 요건에서 면제**된다. 파머스테일은 사업자가
있으므로 반드시 조직으로 가입할 것. 단 조직 계정은 **D-U-N-S 번호**가 필요하고
발급에 며칠 걸릴 수 있다(무료). Apple 도 같은 번호를 쓰므로 **한 번 받아두면
양쪽에 쓴다** — 지금 신청해두면 애플 승인 대기와 병렬로 굴러간다.

### 2. assetlinks 지문은 **업로드 키가 아니라 "앱 서명 키"**
Play App Signing(기본값)을 쓰면 구글이 최종 서명을 다시 한다. 그래서 앱 링크
검증용 SHA-256 은 내가 만든 업로드 키 지문이 아니라 **Play Console →
설정 → 앱 무결성(App integrity) 에 있는 "앱 서명 키 인증서"의 SHA-256** 이다.
둘을 헷갈리면 앱 링크가 조용히 검증 실패한다(앱이 안 열리고 브라우저로 감).
→ 두 지문을 **둘 다** 넣는 게 안전하다(콤마 구분).

### 3. 키스토어를 잃으면 앱 업데이트가 영구 불가
업로드 키스토어(.jks)와 비밀번호는 **여러 곳에 백업**할 것. Play App Signing 을
쓰면 분실 시 구글에 업로드 키 재설정을 요청할 수 있지만, 절차가 번거롭다.

## 0단계 — D-U-N-S 대기(5영업일) 중에 할 것

조직 계정 가입 폼에 D-U-N-S 번호를 입력해야 하므로 **번호가 나와야 가입이
끝난다.** 하지만 아래는 **Play Console 계정 없이 지금 전부 가능**하다 —
대기가 끝날 때쯤 "AAB 만들어 올리기만 하면 되는 상태"가 목표다.

| 작업 | Play 계정 필요? | 비고 |
|---|---|---|
| Android Studio 설치 → 실기기 디버그 빌드 | ❌ | 앱이 폰에 실제로 뜬다 |
| Firebase 프로젝트 + FCM 키 → **푸시 수신 테스트** | ❌ | 구글 계정만 있으면 됨 |
| 릴리즈 키스토어 생성·백업 | ❌ | 3단계 |
| 아이콘 1024 정식 디자인 | ❌ | 2단계 |
| 스크린샷 촬영 | ❌ | 실기기 빌드 후 |
| 심사용 데모 계정 생성 | ❌ | 6단계에서 제출 |
| 토스 PG 심사 문의 | ❌ | 실결제 블로커(별도 트랙) |

권장 순서: **1일차** D-U-N-S 신청 + Android Studio 설치(용량 큼) + PG 문의 →
**2일차** 실기기 디버그 빌드·화면 테스트 → **3일차** Firebase 연결 + 푸시 수신
→ **4일차** 키스토어·아이콘·스크린샷 → **5일차~** 번호 도착 후 가입·업로드.

⚠️ 조급해서 **개인 계정으로 가입하지 말 것** — 유형 변경이 사실상 어렵고,
개인은 클로즈드 테스트 요건에 걸려 5일보다 훨씬 더 밀린다.

## 1단계 — Play Console 계정 (🙋)

- [ ] **D-U-N-S 번호 신청** (없으면) — 무료, 며칠 소요. Apple 과 공용 ⏳
- [ ] https://play.google.com/console → **조직(Organization)** 선택해 가입
- [ ] 등록비 **USD 25 (1회, 평생)** 결제
- [ ] 신원 확인(사업자 등록증·D-U-N-S) 제출 ⏳
- [ ] 개발자 계정 정보 — 앱에 노출될 **개발자명·연락 이메일·주소** 설정

---

## 2단계 — Firebase (푸시 발송용) (🙋 → 값 주면 🤖)

- [ ] https://console.firebase.google.com → 프로젝트 생성 (이름: farmerstail)
- [ ] **Android 앱 추가** — 패키지명 `com.farmerstail.app`
- [ ] **`google-services.json` 다운로드 → `android/app/` 에 저장**
      (이 파일은 비밀값이 아니라 커밋해도 되지만, 우리는 일단 로컬에만 두고
      🤖 가 gradle 배선을 확인한 뒤 결정)
- [ ] **서비스 계정 키 생성**: 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성
      → JSON 다운로드. 여기서 3개 값을 꺼내 Vercel 환경변수로:
      | 변수 | JSON 안의 키 |
      |---|---|
      | `FCM_PROJECT_ID` | `project_id` |
      | `FCM_CLIENT_EMAIL` | `client_email` |
      | `FCM_PRIVATE_KEY` | `private_key` (줄바꿈 `\n` 포함 전체) |
- [ ] ⚠️ 이 값들을 **채팅에 붙여넣지 말 것.** Vercel 대시보드에 직접 입력하고
      "넣었다"고만 알려주면 🤖 가 도달 여부로 확인한다.

## 3단계 — 릴리즈 키스토어 (🙋, Mac/Windows 아무데서나)

```bash
keytool -genkey -v -keystore farmerstail-upload.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias farmerstail
```
- [ ] 비밀번호 2개(키스토어·키) 설정 → **비밀번호 관리자에 저장**
- [ ] `.jks` 파일 **백업 2곳 이상** (클라우드 드라이브 + 외장)
- [ ] ⚠️ 저장소 밖(예: 홈 디렉터리)에 두는 것을 권장. 부득이 `android/` 안에
      둬도 커밋되지 않도록 `android/.gitignore` 의 `*.jks`·`*.keystore` 주석을
      **해제해 뒀다** — Capacitor 기본 템플릿은 이 두 줄이 주석이라 그대로
      두면 서명 키가 공개 저장소에 올라간다(2026-08-09 실측으로 발견해 수정).
- [ ] 지문 확인 (나중에 assetlinks 에 씀):
```bash
keytool -list -v -keystore farmerstail-upload.jks -alias farmerstail
```
      → `SHA256:` 로 시작하는 줄 복사

## 4단계 — 앱 빌드 (🙋 Android Studio)

- [ ] Android Studio 설치 → `android/` 폴더 열기 (Gradle 동기화 대기)
- [ ] 실기기 USB 연결 → Run ▶ 로 **디버그 빌드 설치**
- [ ] 5단계 실기기 테스트 수행
- [ ] 통과하면 릴리즈 AAB:
      Build → Generate Signed Bundle/APK → **Android App Bundle** →
      3단계 키스토어 선택 → release → `app-release.aab` 생성

현재 설정(확인됨): `minSdk 24` (Android 7+), `targetSdk 36`,
`versionCode 1`, `versionName 1.0`, applicationId `com.farmerstail.app`

---

## 5단계 — 실기기 테스트 (🙋, 하나씩 눌러보고 결과 알려주기)

- [ ] 앱 실행 → 스플래시 → 홈 진입
- [ ] **카카오 로그인** (카카오톡 앱 전환·복귀)
- [ ] 알림 설정 → **알림 켜기** → 권한 팝업 허용 → **"테스트 알림" 수신**
      (2단계 FCM 환경변수가 들어가 있어야 실제로 도착함)
- [ ] 알림 **끄기** → 화면 재진입 시 꺼짐으로 표시되는지
- [ ] 로그아웃 → 재로그인 → 알림 상태 정상인지
- [ ] **뒤로가기 버튼**(하드웨어/제스처)으로 화면 계층 이동, 홈에서 한 번 더
      누르면 앱 종료되는지
- [ ] 결제수단 등록에서 **토스 결제창**이 앱 안에서 뜨는지
- [ ] 사진 일기 **카메라·갤러리** 업로드
- [ ] 앱 종료 후 재실행 시 **로그인 유지**
- [ ] 알림 탭 → 해당 화면으로 이동(딥링크)
- [ ] 기기 다크모드 켠 상태에서 화면 깨짐 없는지

## 6단계 — Play Console 등록 (🙋)

### 앱 만들기
- [ ] 앱 이름 `파머스테일` / 기본 언어 한국어 / **앱**(게임 아님) / **무료**

### 스토어 등록정보
- [ ] 짧은 설명(80자): `우리 아이를 위한 맞춤 화식 펫푸드 정기배송`
- [ ] 자세한 설명 — `docs/native-deploy.md` 의 설명문 복붙
- [ ] **앱 아이콘 512×512** (현재 임시 placeholder — 정식 디자인 교체 권장)
- [ ] **그래픽 이미지 1024×500** (스토어 상단 배너) — 새로 필요
- [ ] **휴대전화 스크린샷 2~8장** (최소 2장, 권장 5장)
      1) 홈 오늘의 한 가지 2) 강아지 상세 3) 사진 일기 4) 분석 결과 5) 정기배송
      ⚠️ 실제 고객 정보 노출 금지 — 테스트 계정으로 촬영
- [ ] 카테고리: **쇼핑**, 태그: 반려동물

### 앱 콘텐츠 (전부 필수 — 하나라도 비면 제출 불가)
- [ ] **개인정보처리방침 URL**: `https://www.farmerstail.kr/legal/privacy`
- [ ] **앱 액세스 권한**: 로그인 필요 → **심사용 데모 계정**(이메일/비번) 제공
- [ ] **광고 포함 여부**: 아니요
- [ ] **콘텐츠 등급 설문** → 전체이용가 예상
- [ ] **타겟 고객층**: 18세 이상
- [ ] **데이터 보안(Data safety)** — 우리가 수집하는 것:
      · 개인정보: 이름, 이메일, 전화번호, 주소 (주문·배송)
      · 사진: 사용자 생성 콘텐츠 (일기·체크인)
      · 앱 활동/기기 ID: 푸시 발송용
      · **전송 시 암호화됨: 예 / 데이터 삭제 요청 가능: 예**
- [ ] **계정 삭제 URL**: `https://www.farmerstail.kr/mypage`
      (앱 안 마이페이지에 회원 탈퇴 구현돼 있음 — Play 필수 항목)
- [ ] 정부 앱 아님 / 금융 앱 아님 체크

### 출시
- [ ] **내부 테스트** 트랙에 AAB 업로드 → 본인 계정 테스터 등록 → 설치 확인
- [ ] 🤖 **앱 서명 키 SHA-256 지문** 을 알려주면 (Play Console → 설정 →
      앱 무결성) `ANDROID_FINGERPRINTS` 환경변수 배선 → 앱 링크 활성화
- [ ] 프로덕션 트랙 제출 ⏳ (심사 보통 1~3일, 첫 앱은 최대 7일)

## 7단계 — 심사 반려 시 자주 나오는 것

| 반려 사유 | 대응 |
|---|---|
| 데이터 보안 양식 불일치 | 앱이 실제로 수집하는 항목과 양식이 달라서 — 위 목록대로 정확히 |
| 계정 삭제 경로 없음 | 마이페이지 회원 탈퇴 URL 회신 |
| 로그인 불가(심사자) | 데모 계정 상태 확인 후 재제출 |
| 권한 사용 사유 불명확 | 알림·카메라 권한이 어디 쓰이는지 설명 회신 |
| 웹뷰 전용 앱 | 네이티브 푸시·앱 링크·스플래시 사용 중임을 회신 |
